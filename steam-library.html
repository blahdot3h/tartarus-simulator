Move the game out of Program Files

Chrome and Edge won't let any website open a file inside C:\Program Files or C:\Program Files (x86). When you try, they say the folder “contains system files”. Steam installs games in C:\Program Files (x86)\Steam unless you choose otherwise, so Auto Screenshot Mode's Or choose the file button can't open Torchlight: Infinite's log there. The way around it is to move the game somewhere else. Steam does the moving for you: nothing is downloaded again, and your characters aren't touched, since they're kept on the game's servers.

You may not need this. On Auto Screenshot Mode, you can drag UE_game.log from File Explorer onto the page instead, and that works wherever the game is installed. Move the game only if you'd rather use the button, or if dragging doesn't work for you.

Where is your game now?

  1. In Steam, open your Library, right-click Torchlight: Infinite, then choose Manage, then Browse local files.
  2. File Explorer opens the game's folder. Click the address bar at the top to see its full path.

If the path starts with C:\Program Files or C:\Program Files (x86), read on.

If it doesn't (say it's D:\SteamLibrary\steamapps\common\Torchlight Infinite), there's nothing to move. Go back to Auto Screenshot Mode and pick UE_game.log in UE_game\TorchLight\Saved\Logs, inside that folder.

Which way fits your PC

Steam keeps games in libraries: folders it looks after. It allows one library on each drive, and Steam's own folder counts as the library of the drive it's on. So it depends on whether you have a second drive.

You have another drive A D:, E: or other drive inside the PC, or an external drive with room for the game. You make a Steam library there and move the game to it. Make a second library → You only have C: Steam won't add a second library on C:. Instead, you move Steam itself, games and all, out of Program Files. Move Steam →

Not sure? Open File Explorer and click This PC: your drives are listed under Devices and drives, each with its free space. The new place needs as much free space as the game uses now. Steam shows how much that is in Settings, then Storage, next to the game.

With another drive: make a second library

1. Make the library

  1. In Steam, click Steam at the top left, then Settings, then Storage.
  2. At the top of Storage is a drop-down showing a drive, such as Local Drive (C:). Open it and choose Add Drive.
  3. Pick your other drive in the list and press Add. Steam makes a folder called SteamLibrary at the top of that drive, such as D:\SteamLibrary.

To put the library in a folder of your own choosing, pick Let me choose another location instead, then choose or make an empty folder: not the drive itself (D:\), and nothing inside Program Files. If your drive isn't in the list, it already has a Steam library, so skip to moving the game and use that one. An external drive works, but it has to be plugged in whenever you play.

2. Move the game

  1. Close Torchlight: Infinite. If Steam is updating it, let the update finish first.
  2. In Settings, then Storage, choose the drive the game is on now (C:) in the drop-down at the top.
  3. Tick the box next to Torchlight: Infinite, then press Move at the bottom right.
  4. Choose your new library and press Move.
  5. Leave Steam open until it's done. Steam copies the game to the new library, then removes the old copy. Large games take a while, so don't shut the PC down in the middle.

Another way to the same Move: right-click the game in your Library, then Properties, Installed Files, and Move install folder.

Done? Connect the log again.

With only C: move Steam out of Program Files

Steam won't make a second library on the drive it's installed on. Instead, you move Steam's whole folder, with your games inside it, to a folder outside Program Files, such as C:\Steam. On the same drive this takes moments, since nothing is copied. Valve's Steam Support has an article about this too, called Moving a Steam Installation and Games.

  1. Close the game. Then quit Steam completely: right-click the Steam icon near the clock (it may be under the ^ arrow) and choose Exit. Closing Steam's window isn't enough.
  2. Open File Explorer and go to C:\Program Files (x86).
  3. Right-click the Steam folder and choose Cut.
  4. Go to C:\ (This PC, then Local Disk (C:)), right-click an empty spot and choose Paste. Windows asks for administrator permission, since the folder is leaving Program Files: choose Continue. If Windows says a file is in use, Steam is still running: end it in Task Manager and try again.
  5. Open the new C:\Steam folder and double-click steam.exe. Steam updates itself for a moment, then opens as usual with your games installed. Sign in if it asks.
  6. Your old shortcuts to Steam still point to Program Files, so make a new one. Right-click steam.exe, choose Show more options (on Windows 11), then Send to, then Desktop (create shortcut). While Steam is running, you can also right-click its taskbar icon and choose Pin to taskbar.

To check it worked, right-click Torchlight: Infinite, then choose Manage, then Browse local files: the path should now start with C:\Steam. If the game won't start, right-click it, then choose Properties, Installed Files, and Verify integrity of game files.

Done? Connect the log again.

Not on Steam?

If you play with the game's own launcher, the game has a folder of its own, often C:\Program Files (x86)\Torchlight Infinite. We don't know of a way to move it there. Instead, uninstall the game and install it again. When the installer asks where to put it, choose a folder outside Program Files, such as C:\Games\Torchlight Infinite. The game downloads again, but your characters are on the game's servers. The log is then in Game\UE_game\Torchlight\Saved\Logs inside that folder.

Then, on Auto Screenshot Mode

The game's log is now in its new place. If you made a library on another drive, it's here, with your drive's letter instead of D:

D:\SteamLibrary\steamapps\common\Torchlight Infinite\UE_game\TorchLight\Saved\Logs

If you moved Steam to C:\Steam, it's here:

C:\Steam\steamapps\common\Torchlight Infinite\UE_game\TorchLight\Saved\Logs
  1. Start the game once, so it writes its log in the new place.
  2. The log Auto Screenshot Mode remembered moved with the game, so give it the log again. On Auto Screenshot Mode, press Or choose the file.
  3. In the window that opens, paste the folder into the address bar at the top, press Enter, and pick UE_game.log. Or drag the file from that folder in File Explorer onto the box in step 1.

Questions

  • Can't I make a shortcut to the log instead? No. Chrome and Edge check where a shortcut or link really leads, and refuse it if that's inside Program Files.
  • Is it only this site? No. It's the browser's rule, for every website: it keeps sites away from your programs and from Windows itself.
  • Is moving safe? Steam copies the game before it removes the old copy, and your characters are on the game's servers. Just don't turn the PC off in the middle of a move.
  • Will the game still update? Yes. Steam updates it in its new library, as before.
